# Project help

## Opening a result

Choose a project, then select its map, dashboard, story or video. The full workspace provides additional GIS tools.

## Exporting

An export action opens the corresponding browser tool. Review the settings and save the generated file. A published download opens an existing file.

## A map does not load

Interactive maps need WebGL2 and accessible public map sources. Reload once. Use the project summary, sources and available published files if the map remains unavailable.

## Updating a project

Copy the project link into ChatGPT and describe the required change. Project edits and refreshed sources belong in a reviewed GitHub change.


## Mobile export

On iPhone and iPad, use Safari's download/share interface to save the generated
file. Keep the video tab visible throughout recording. Memory limits can prevent
large recordings. Start with a short preview. A missing codec or WebGL2 renderer
is reported at the export action. Reduced-motion preferences disable animated
camera transitions in the preview. Playback always starts with your action.
