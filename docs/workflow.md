# Create a project with ChatGPT

Describe a question, place, source year and desired result. Ask ChatGPT to record sources and calculations in this repository and publish a project page.

The workflow uses your GitHub connection in ChatGPT. This website presents projects and prepares browser exports.

[Browse examples](projects.md){ .md-button }
[Read the authoring protocol](chatgpt-project-protocol.md){ .md-button }

## Start a new analysis

<label for="new-project-request">ChatGPT request</label>
<textarea id="new-project-request" rows="10" readonly>Create a GeoLibre research project in Equilibriumpress/geolibre-projects.
Question: [what do you want to understand?]
Place and geographic unit: [city, neighbourhoods, grid, region]
Data year: [year or latest published data]
Preferred public sources: [publisher or leave open]
Outputs: [map, dashboard, story, print, atlas, data, video]
Record source dates, licenses, missing-value rules and formulas. Use projects/_template, keep analytical logic in SQL, validate references and publish a project page through GitHub.</textarea>

## Examples of updates

- Refresh the source year and explain changes in the calculation.
- Add a comparison scenario using the existing indicators.
- Make a 30-second vertical video using verified project results.
- Improve the legend and print layout without changing the analysis.

The copy action prepares text. Open ChatGPT yourself and use your GitHub connection to submit the request.
